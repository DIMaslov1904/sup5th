# SUP 5th

Расширение для работы с проектами и доступами, автологина и SEO-анализа страниц.

## Браузеры и установка

Скачайте пакет из [Releases](https://github.com/DIMaslov1904/sup5th/releases), раздел **Assets**.

| Браузер | Пакет | Установка |
| --- | --- | --- |
| Chrome 130+; Edge, Opera, Яндекс Браузер на Chromium 130+ | `sup5th-chromium-v*.zip` | Распаковать → менеджер расширений → режим разработчика → «Загрузить распакованное расширение». |
| Firefox Desktop 140+ | Подписанный `.xpi` | Перенести скачанный xpi файл в окно браузера |

После установки разрешите доступ к нужным сайтам и API. Выберите источник данных при первом запуске или в «Настройки» → «Загрузка». Обновления устанавливаются вручную из Releases.

## Ограничения

**Firefox**

- Биометрия экспериментальна: открывается в отдельной вкладке; известна ошибка WebAuthn `The operation is insecure`.

## Стек и сборка

Manifest V3 · Vue 3 · JavaScript / TypeScript · Vite 8 · Tailwind CSS 4 · CRXJS · IndexedDB / Web Crypto.

Установите зависимости командой `npm ci` на Node.js 24.13.1.

| Команда | Результат |
| --- | --- |
| `npm run dev` | Режим разработки для Chromium |
| `npm run dev:firefox` | Режим разработки для Firefox |
| `npm run build` | Сборка Chromium в `dist/` |
| `npm run build:firefox` | Сборка Firefox в `dist-firefox/` |
| `npm run release` | Проверка типов, обе сборки и два ZIP-пакета в `release/` |

Команда `release` готовит `sup5th-chromium-v<версия>.zip` для Chromium и `sup5th-firefox-v<версия>.zip` для подписи Firefox. Публикация в GitHub Releases выполняется вручную. Для Firefox в релиз добавляется подписанный `.xpi`.

## API

### Панель управления проектами

1. В панели откройте «Мой профиль» → «SUP 5th», создайте строку подключения и скопируйте её.
2. В расширении откройте «Настройки» → «Загрузка» и выберите «Панель управления проектами».
3. Вставьте строку подключения в одно поле и нажмите «Сохранить и загрузить».

Строка содержит адрес панели и бессрочный токен. Для рабочей панели задайте HTTPS-адрес в `APP_URL`. Локальный Docker может использовать `http://127.0.0.1:8000`. Расширение загружает проекты и доступы через `/api/v1/sup5th/projects` и `/api/v1/sup5th/accesses` с заголовком `Authorization: Bearer <токен>`. Токен хранится локально. Если включена защита, он шифруется и загрузка из панели выполняется после разблокировки.

При смене источника нажмите «Загрузить всё», чтобы заново заполнить каталог. Настройки обоих источников сохраняются. Данные обновляются раз в сутки и вручную из раздела «Загрузка».

### Google Таблица

Укажите два адреса Google Apps Script. Запросы отправляются с cookies Google. Доступ определяется настройками Apps Script.

Примеры запросов (`PROJECTS_ID` и `ACCESS_ID` — идентификаторы развёртываний):

```http
GET https://script.google.com/macros/s/PROJECTS_ID/exec
GET https://script.google.com/macros/s/ACCESS_ID/exec
```

Ответ проектов. Порядок полей: название, сайт, инструкция, админка, CMS, ключ тикета, Git.

```json
{
  "result": [
    ["Проект", "https://example.org", "Инструкция", "https://example.org/admin/", "Битрикс", "ticket-key", "https://git.example.org/project"]
  ]
}
```

Ответ доступов. `access`: название, сайт, логин, пароль, FTP-хост, FTP-логин, FTP-пароль. `services`: название, URL, логин, пароль.

```json
{
  "result": {
    "access": [
      ["Проект", "https://example.org", "login", "password", "ftp.example.org", "ftp-user", "ftp-password"]
    ],
    "services": [
      ["Сервис", "https://service.example.org", "login", "password"]
    ]
  }
}
```

Пустые значения — `""`. Несколько логинов и соответствующих паролей разделяются `\n`. Префикс `!` у сайта (`!https://example.org`) исключает поддомены; без него запись действует и на них.
