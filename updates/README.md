# Обновления

## Firefox

Постоянный адрес из manifest:

```text
https://raw.githubusercontent.com/DIMaslov1904/sup5th/main/updates/firefox.json
```

ID — `sup5th@5th.ru`. Workflow **Publish release metadata** формирует JSON из стабильного подписанного XPI: версия, минимальный Firefox, ссылка на конкретный пакет и SHA-256. Неподписанный ZIP, Chrome ZIP и Opera ZIP этот канал не меняют. Пустой `updates` означает, что подписанная версия пока не опубликована.

## Opera и Chrome

`opera.json` и `chrome.json` — справочные данные о последних стабильных ZIP: версия, ссылка, SHA-256 и минимальная версия Chromium. Это **не** нативные манифесты автообновлений браузеров.

Распакованные сборки обновляются вручную. Для пользователей дополнения, установленного из Opera Add-ons, обновления выпускаются через **Upgrade** в кабинете магазина. После одобрения магазин распространяет их сам; подменять его канал ссылкой на GitHub не нужно.

Метаданные не допускают понижения версии и замены содержимого под прежним номером. [Полный порядок выпуска](../docs/RELEASING.md).
