# Проверка SUP 5th

Сценарий Яндекс ИКС по кнопке относится к версии 4.0.3 и новее; в старых сборках счётчик загружается автоматически.

Используйте отдельный профиль браузера: подключение примеров заменяет текущий каталог. Все учётные данные вымышленные и не дают доступа к реальным сервисам. Вход в Google, рабочие таблицы и внутреннюю поддержку для проверки каталога и SEO не нужен.

## Порядок проверки

1. Установите сборку и откройте расширение. На шаге «Проекты» вставьте прямой URL `projects.json` и нажмите «Подключить проекты».
2. На шаге биометрии нажмите «Пропустить». Проверка устройства необязательна для тестовых данных; биометрия Firefox пока экспериментальная.
3. На шаге доступов вставьте прямой URL `accesses.json` и нажмите «Подключить и завершить».
4. Откройте каталог нажатием на строку поиска. Должны появиться **2 проекта, 3 доступа к сайтам и 2 сервиса**. У Example.com — два логина; FTP/SSH-поля относятся только к первому из них. Проверьте поиск, раскрытие доступов и копирование вымышленных паролей. Один из сервисов не содержит логина и пароля.
5. Откройте [https://example.com/](https://example.com/) в обычной вкладке, затем расширение → «SEO». Должен появиться отчёт о странице без автоматической загрузки Яндекс ИКС.
6. Нажмите «Получить» у Яндекс ИКС: только теперь выполняется запрос к Яндексу с доменом `example.com`. При сетевой ошибке доступна кнопка «Повторить». Закройте SEO и откройте снова: загрузка требует нового нажатия.

Для уже настроенного расширения замените API в «Настройки» → «Подключение», затем выполните загрузку в разделе «Загрузка».

Примеры проверяют формат API, каталог и копирование. У сайтов example.com/example.org нет форм входа для этих вымышленных учётных записей; автологин на них проверить нельзя. Интеграция с support.5th.ru требует отдельного рабочего аккаунта. Реальная биометрия требует поддерживаемого устройства и проверки вручную.

## Фоновая работа

Расширение раз в неделю обновляет данные из настроенных API и кеширует иконки сайтов. На support.5th.ru локально учитывает время работы с тикетом; при бездействии блокирует защищённые доступы. Сетевые SEO-проверки запускаются при открытии SEO, Яндекс ИКС — по явному нажатию «Получить».
